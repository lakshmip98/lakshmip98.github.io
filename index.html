ADX & CrewAI Investment Advisor

Issue:
ADX: As a trader, I want to utilize the Average Directional Index (ADX) integrated with CrewAI agents to identify and analyze the strength of market trends, so that I can receive informed investment decisions and make strategic trading choices.

This project delivers a Streamlit application that calculates the Average Directional Index (ADX) for user-specified stocks, fetches both historical and real-time price data, and integrates CrewAI agents to generate actionable BUY, SELL, or HOLD signals based on the latest ADX readings. My contributions include architecting and implementing the ADX calculation module, designing the Streamlit user interface, wiring data-fetching pipelines, developing and tuning the CrewAI decision agent, and building a backtesting engine to validate strategy performance.

This project implements a Streamlit-based application that:

  • Fetches historical and real-time stock data;
  • Calculates the Average Directional Index (ADX) with user-defined parameters;
  • Leverages CrewAI agents to generate precise BUY, SELL, or HOLD signals based on the latest ADX;
  • Provides a backtesting framework to evaluate ADX-driven strategies.
My contributions: architected and implemented the ADX calculation module, designed the Streamlit UI, integrated data feeds, created and tuned the CrewAI decision agent, and built the backtesting engine.

User Stories & Tasks

Below is a concise summary of each key user story, with the tasks completed and a brief description of what was delivered.

  • ADX Integration
    Developed the core ADX calculation logic, allowing users to customize the period and smoothing method. This ensures accurate measurement of trend strength and forms the foundation for trading signals.
  • Data Fetching
    Implemented robust pipelines for historical (1 year, 6 months, 3 months, 1 month) and intraday (1 minute) data using yfinance and yahooquery, including error handling and user feedback.
  • Streamlit UI
    Designed and coded the interactive interface: ticker input, data-type selector, parameter controls, and dynamic tables displaying the latest fetched and computed datasets.
  • CrewAI Agent
    Engineered the prompt structure and task definitions so the CrewAI agent returns a precise one-word decision (BUY, SELL, or HOLD) based on the most recent ADX value and current price.
  • Backtester
    Built a backtesting module that runs the ADX-signal strategy over historical data, computes performance metrics (Sharpe ratio, max drawdown), and outputs summary statistics for validation.
